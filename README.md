# Dread Forge

Prompts for building software with coding agents using public security guidance.

[`spec-driven/`](spec-driven/README.md) holds the spec-driven bootstrap: thirteen self-contained prompts that take a project from rough notes to specs, a GitHub backlog, and tested code on a stack chosen for the project. They run in order using project files and public resources, with no commercial prompt collection or private repository required. Step 06 includes the full requirement template, so no separate template download is needed. The workflow uses Grim Prompter for threat modeling, Dread Ledger for security logging, Trim Reaper for dependency discipline, and public security guidance for the selected stack.

## Getting started

Clone this repository, open the [step-by-step guide](spec-driven/README.md), and paste each prompt into your coding agent in order. Start with your project notes in step 01.

```sh
git clone https://github.com/jmanico/dread-forge.git
```
